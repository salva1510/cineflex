CineFlex FreeReels — Maramihang Public-Domain Starter Catalog

This build adds 47 playable entries sourced from Wikimedia Commons' category:
"Videos of films in the public domain".

IMPORTANT:
- The catalog links to Wikimedia Commons media through Special:Redirect/file/.
- Each file page is the authoritative place to verify the exact license/status.
- Do not assume every file is commercially reusable merely because it appears in a category.
- For a monetized CineFlex deployment, review the individual file's license and any
  separate music/audio/personality/publicity rights before publishing.
- This build does not copy the video files into your hosting; playback is remote.

Files:
- freereels.html
- freereels.css
- freereels.js
- freereels-catalog.json

The vertical player, swipe navigation, auto-next, likes, My List and progress
saving from the previous build are retained.

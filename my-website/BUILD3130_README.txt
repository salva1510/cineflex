CINEFLEX BUILD 313.0 — UNIVERSAL SMART TV / REMOTE UI

WHAT CHANGED
- Automatic Android TV, Google TV, Fire TV, Samsung Tizen, LG webOS, VIDAA, Sony BRAVIA and generic Smart TV detection.
- Large, high-contrast remote focus indicator.
- Geometry-based directional navigation for buttons, posters, episodes, recommendations, server tabs, menus and dialogs.
- Android TV key codes and common Samsung/LG/Hisense Back key support.
- TV homepage changes bottom navigation into a left-side remote rail.
- Larger poster cards, headings, hero actions and menu drawer targets.
- TV-optimized watch page with larger player, server buttons, episode grid and controls.
- Enter/OK activates the selected item; Back closes the active overlay first, then returns to the previous page.
- Dynamic content is automatically added to remote navigation.
- T key can toggle TV mode on a computer for testing.

IMPORTANT LIMITATION
Smart TV browser engines differ. This build supports browser-based navigation across major TV platforms, but DRM, codecs, third-party iframe controls and orientation/fullscreen behavior still depend on each television and streaming server.

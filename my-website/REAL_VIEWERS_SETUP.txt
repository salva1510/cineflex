CINEFLEX UNIFIED REAL VIEWERS — SETUP

1. Upload all updated website files.
2. In Firebase Console, open Firestore Database > Rules.
3. Replace the current rules with the included firestore.rules, then click Publish.
4. Clear the website/PWA cache or redeploy with cache invalidation.
5. Test using two different browsers/devices. Keep both pages visible for 20-30 seconds.

How counting works:
- Each open browser tab receives a unique session ID.
- Guests and logged-in members are both counted.
- Home, Details, Watch, Vivamax, Library, Profiles and VIU pages send heartbeats.
- A viewer remains online for up to 120 seconds after the last successful heartbeat.
- Sleeping TVs, closed browsers, lost internet, ad blockers or blocked Firestore requests can still delay/remove presence.

Important: The count represents active browser sessions, not guaranteed unique people. One person using two devices/tabs can count twice.
